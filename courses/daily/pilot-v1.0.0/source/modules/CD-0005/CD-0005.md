## Employee-facing content

### 1. Today’s skill

Match common screw-drive shapes to the corresponding hand screwdriver and recognize when tip size still needs confirmation.

### 2. Why it matters

A screwdriver can look close to the right choice without fitting correctly. Matching both drive type and tip size helps reduce slipping and damage to the screw or tool.

### 3. Learn it

**Match the drive shape first, then confirm the tip size.** The drive is the slot or recess where the screwdriver engages—not the screw head’s outer shape.

Start with these common patterns:

| Drive type | Recognition clue | Matching hand tool |
|---|---|---|
| **Slotted** | One straight slot across the screw head | Slotted screwdriver, commonly called a **flathead**, **flathead screwdriver**, or **flat-blade screwdriver** |
| **Phillips** | A cross-shaped recess | Phillips screwdriver |
| **Square** | A square recess | Square-drive screwdriver |
| **TORX** | A six-lobed, star-like recess | Correctly sized TORX screwdriver |

**Why “slotted”?** The name describes the straight slot that receives the screwdriver’s blade. Customers commonly call the matching tool a **flathead**—recognize both names. When discussing screws, keep drive type separate from head shape: “slotted” identifies where the tool engages, while “flat head” can describe the screw’s outer head shape. [Sources 6 and 7]

These are starting clues. Unfamiliar, combination, or specialty drives need closer identification before you choose a tool.

**Recommended action:** Check the screw package or manufacturer information for the specified drive type and size. Then match that designation to the screwdriver’s marking. Shape identifies the family; it does not establish the size.

For example, Phillips screwdrivers come in different tip sizes. Choosing “a Phillips” is only the first step. Klein Tools advises matching both screwdriver type and size to the screw. [Source 1]

**Common mistake:** Choosing by handle size or shaft length. A longer screwdriver does not necessarily have a larger tip. Read the tip designation.

**When to verify or seek help:** If a tip will not seat properly or slips, stop and recheck the type, size, and condition rather than forcing it. Ask a knowledgeable coworker when the drive is unfamiliar or damaged.

Some cross-shaped drives, including Phillips and Pozidriv, have separate tool designations. Likewise, do not assume every star-like recess uses the same driver. Verify the exact designation. [Sources 3 and 5]

### 4. Customer scenario

A customer is assembling a cabinet by hand. The screw package specifies **“Phillips #2.”** They have found the Phillips screwdrivers but see several tip sizes and shaft lengths.

They ask which detail to match before choosing one.

### 5. Quick check

**Question ID: CD-0005-Q01**

Which selection best matches the package specification?

A. A Phillips screwdriver with the longest shaft
B. A square-drive screwdriver marked #2
C. A Phillips screwdriver with a #2 tip
D. A Phillips screwdriver with the largest handle

### 6. Take it to the floor

Match **drive type + tip size**. Choose shaft length and handle features after establishing the correct tip.

## Reviewer and manager materials

### Answer key — separate from employee-facing content

- **Question ID:** CD-0005-Q01
- **Correct answer:** C. A Phillips screwdriver with a #2 tip
- **Explanation:** “Phillips #2” identifies both the drive type and tip size. A square #2 is a different drive type. Shaft length and handle size do not establish the required tip designation.
- **Teaching reference:** Section 3, “Learn it,” opening rule, “Recommended action,” and “Common mistake.”
