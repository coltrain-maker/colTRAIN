## Learning paths

### New Retail Employee

Core courses: RF-101, RF-102, RF-103, RF-104, CS-101, CS-103.

### Sales Floor Associate

Core courses: CS-102, HT-101, HT-102, HT-103, IM-103.

### Department Specialist

Eligible selection: HB-101, HB-102, HB-103, HB-104, PD-101, PD-102, PD-103, LG-101, LG-102.

Choose 2–4 relevant courses per specialization; do not automatically assign all options.

### Inventory & Merchandising Associate

Core courses: IM-101, IM-102, IM-103.

### Department Lead/Supervisor

Core courses: BL-101, BL-102, BL-103.

Add relevant department courses chosen by the manager; specific optional-course mapping is not yet defined.

### Store Manager/Owner

Core courses: BL-101, BL-102, BL-103, IM-101, IM-102, IM-103.

Future advanced training may be added later; no extra course codes are assigned yet.

Learning paths reference the same course records. Completion is shared across paths. The current implementation adds library browsing labels, not automatic path assignment, placement tests, prerequisite gates, or separate path completion tracking.

The Department Lead/Supervisor optional department-course list was not specified; only the three named BL core courses are mapped. The existing customer-trust sample keeps its current name and identity rather than being silently renamed to CS-101 or CS-103.
