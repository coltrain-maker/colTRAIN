# colTRAIN | Three-Level Learning Framework

Course Development Standard · Version 2.0 · October 2026

“Learn together. Grow together.”

We're adopting a three-level learning model for colTRAIN:

Level 1 — Foundations

Learn what it is and why it matters.

Builds essential knowledge, confidence, and basic workplace skills.

Level 2 — Application

Use what you know to solve problems.

Develops product-selection skills, customer consultation, and practical judgment.

Level 3 — Expertise

Handle complexity and help others grow.

Develops advanced problem-solving, product knowledge, coaching, and leadership.

These are training levels, not employee classifications. A store manager may need Foundations training in gardening. An experienced paint associate may qualify for Expertise-level paint training.

## 1. Updated course development standard

Our existing eight-section course template remains in place. We'll add the following fields and requirements.

| Standard             | New requirement                                           |
| -------------------- | --------------------------------------------------------- |
| Skill level          | Foundations, Application, or Expertise                    |
| Required knowledge   | List the skills or courses employees should know first    |
| Learning objectives  | Use measurable actions appropriate to the level           |
| Lesson complexity    | Match explanations, examples, and decisions to the level  |
| Assessment depth     | Test knowledge, application, or advanced judgment         |
| Learning progression | Identify related courses at other levels                  |
| Intended audience    | Define the employee's knowledge needs, not just job title |

### Instructional standards by level

|                    | Foundations                | Application                             | Expertise                                  |
| ------------------ | -------------------------- | --------------------------------------- | ------------------------------------------ |
| Teaching style     | Explain and demonstrate    | Apply and compare                       | Analyze and evaluate                       |
| Employee challenge | Recognize the right action | Choose the best solution                | Resolve complex situations                 |
| Scenarios          | Simple and realistic       | Multiple factors                        | Incomplete or conflicting information      |
| Questions          | What? Why? Which action?   | How? Which option fits?                 | What caused this? What should happen next? |
| Expected outcome   | Basic competence           | Independent judgment within role limits | Advanced judgment and coaching             |

All three levels will continue to use short, plain-language lessons. Advanced training should mean more difficult thinking, not more difficult reading.

This structure supports both guided development and independent exploration.

Employees could browse topics relevant to their work. Managers would still control which courses are assigned. Administrators would continue controlling course availability by store.

## 5. Assessment and progression rules

Our existing assessment rules remain unchanged.

- Employees complete required lessons before their first course quiz.
- Final quizzes use four answer choices per question.
- The passing score is 80%.
- Employees receive three attempts before requiring manager assistance.
- Each correct question earns 10 lifetime points only once.
- Passing awards one standard course trophy.
- Competition scores remain separate from lifetime points.
- Repeating a passed quiz does not award duplicate lifetime points or trophies.

### Future placement assessments

I recommend adding a placement assessment feature later.

Experienced employees could demonstrate their knowledge and potentially bypass introductory instruction.

However, this is not part of the current development standard. We will need separate rules for placement eligibility, passing requirements, course credit, and safety-related exceptions.

Until then, the current lesson and quiz requirements apply to everyone assigned a course.

## 6. How we'll develop courses going forward

I recommend building courses in this order:

Phase 1 — Complete the 25 Foundations courses

Continue with CS-102 and the rest of the approved launch catalog. Include meaningful customer and workplace scenarios in each course.

Phase 2 — Build priority Application courses

Start with hardware, plumbing, electrical, paint, and lawn and garden. These areas offer strong opportunities for practical product-selection training.

Phase 3 — Develop Expertise courses

Involve experienced hardware professionals in reviewing advanced scenarios. Validate technical claims using appropriate manufacturer or authoritative sources.

## 7. Updated course delivery requirements

Each course will continue to be delivered as a ZIP with:

1. Complete Markdown course document.
2. Matching full-content JSON.
3. README with version history, missing materials, and unresolved questions.

We'll add the skill level, prior knowledge, and learning progression fields to both the Markdown and JSON. Every package will remain marked Ready for review until approved.

No SQL, database tables, application code, or deployment instructions will be included. Codex will handle the Supabase integration.

### Recommendation for our next course

We should continue with CS-102: Selling Skills for Hardware Retail, our next approved Foundations course.

This is also a good opportunity to establish the difference between our levels. CS-102 will teach the fundamentals of selling. A future Application course can focus on consultative selling and planning customer projects. An Expertise course can focus on complex consultations and coaching other employees.

That gives colTRAIN a consistent progression without forcing experienced employees to learn the same material repeatedly.

The three-level learning model is now our agreed course-development direction. The original 25-course catalog and six learning paths remain preserved.
